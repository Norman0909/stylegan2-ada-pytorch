# 增广前后训练对比报告

## 实验设计

- **模型**: yolo26n(本地 ultralytics fork 8.4.118)
- **配置对齐**: 300 epochs / batch 24 / imgsz 640 / seed 42 / deterministic / cos_lr / close_mosaic 10 / amp,两者完全一致
- **基线**: 原始 UATD 训练集(7341 图,metal bucket 390 实例)
- **增广**: 原始训练集 + StyleGAN2-ADA 生成的 697 张 metal bucket 贴入样本(metal bucket → 1087 实例)
- **评估集**: 独立 test 集(919 图,训练全程未用)
- **增广方式**: StyleGAN2-ADA 800 kimg 生成 → 阈值提取前景 → 随机缩放/旋转/翻转 → 按真实位置分布(右下角)+ IoU 拒绝重叠 → 贴入背景,保留原标签 + 新增框

## 结论

1. **目标类显著提升**: metal bucket mAP50 **+3.81%**(0.9317→0.9698),mAP50-95 **+2.61%**。增广直接改善了最稀少的类。
2. **整体不降反升**: 平均 mAP50 +0.66%,mAP50-95 +1.10%。
3. **部分类轻微下降**(square cage -1.92%、circle cage -0.68%)在单 seed 噪声范围内,非系统性退化。
4. StyleGAN2-ADA 对稀有类金属桶的增广**有效**。
